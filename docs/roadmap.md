# Roadmap

## Initial offline release

- WooCommerce core and Shopify current/legacy product CSV adapters.
- Shared offer and available-stock inputs.
- Evidence-led action reports and reusable AI skill instructions.
- Synthetic examples and automated tests; live-store and AI application validation pending.

## Next validation work

1. Test a fresh WooCommerce development-store export and a Shopify development-store export against the documented guides, including variants, inventory and scheduled offers.
2. Validate the skill workflow in the AI applications we intend to document.
3. Record sample demonstrations and write the first accompanying article from the tested output.
4. Add native inventory imports or read-only connections where they remove meaningful setup work. Test access and pagination before claiming support.
5. Add optional automated public-page observations with explicit scope and clear limits.

## Later series builds

Product opportunity finder; Analytics reporting; Search Console opportunities; weekly marketing analyst; post-sale review; search-results research with DataForSEO; content refresh; Clarity review; page prioritisation; Merchant Center diagnostics; product listing improvements; bundle research; Google Ads search-term review; Meta creative review; repeat purchases; promotion contribution; combined ecommerce priorities.

All ecommerce builds target both WooCommerce and Shopify. These later tools are planned, not implemented here.
